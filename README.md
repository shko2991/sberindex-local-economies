# Потребление против рынка труда: типы локальных экономик муниципалитетов

Конкурс СберИндекса, направление «Кластеризация». Типология муниципальных образований (МО)
по безналичному потреблению на динамической атрибутированной сети и её сопоставление с
типологией по рынку труда (муниципальная статистика Росстата).

> Статус: готовы типология потребления, сравнение методов, динамика и интерактивная страница.
> В работе — слой рынка труда (муниципальная статистика Росстата). Отчёт: [`reports/report.md`](reports/report.md).

## Главное

- 2 016 МО с полным рядом безналичных расходов (2023–2024), четыре семейства рёбер (состав
  расходов, синхронная динамика, DTW, дороги) и их мультиплекс.
- 280 вариантов разбиения: k-means, GMM, Уорд, паттерны (Мячин), Leiden, спектральная,
  KEFRiN (реализован по статье Shalileh & Mirkin, 2022) с разными расстояниями и весом сети.
- Выбор — шесть ICVI (SW, CH, S_Dbw, AVI, AVU, MQ), агрегирование рангов по Борда и Коупленду
  (одинаковый победитель), устойчивость на подвыборках. Итог: KEFRiN на мультиплексе, 8 типов,
  ARI = 0,65.
- Внешняя проверка: типы объясняют 66% дисперсии индекса доступности рынков (η² = 0,655),
  который в кластеризации не участвовал.
- 70% МО сохраняют тип все 8 кварталов; 9% сменили тип и закрепились в новом.

## Как воспроизвести

```bash
pip install -r requirements.txt
python src/download.py                      # архив конкурса с официального адреса
python src/download.py --dict t_dict_municipal.rar   # справочник МО СберИндекса (скачать вручную)
python src/download.py --check              # проверка файлов и контрольных сумм
python src/compare.py                       # сетка методов → 6 ICVI → ранжирование → устойчивость (~30 мин)
python src/pipeline.py                      # итоговое разбиение, описания АФП, динамика, проверки
python src/synthetic.py                     # синтетическая проверка KEFRiN
python src/figures.py                       # рисунки отчёта
python src/landing_data.py && python landing/build.py   # интерактивная страница → docs/index.html
python -m pytest tests -q                   # проверки методов на синтетике
```

Все параметры — в `config/config.yaml`; другой конфиг: `SBER_CONFIG=path/to/config.yaml`.
Случайность фиксирована (`seed`).

## Данные

| Источник | Что берём | Лицензия |
|---|---|---|
| Архив конкурса СберИндекса (`hackathonlicence.zip`) | безналичные расходы по МО и категориям за 2023–2024 гг. (месяц), индекс доступности рынков, расстояния между центрами МО | CC BY-SA 4.0 |
| [Справочник МО СберИндекса](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities) | названия, регионы, ОКТМО по версиям, полигоны | условия СберИндекса |
| [Муниципальная статистика России (Точно)](https://tochno.st/datasets/bdmo) | зарплата и численность работников, население, розничная торговля | CC BY 4.0 |

Данные в репозиторий не кладутся: их скачивает `src/download.py`.

## Структура

```
config/config.yaml   все параметры
src/data.py          загрузка и проверка данных, базовая выборка (2 016 МО с полным рядом)
src/features.py      признаки МО: структура (CLR долей), уровень, динамика; квартальные признаки
src/graphs.py        четыре семейства рёбер: структура, совместная динамика, DTW, география
src/methods.py       k-means, GMM, Уорд, паттерны (Мячин), Leiden, спектральная, KEFRiN
src/icvi.py          SW, CH, S_Dbw, AVI, AVU, MQ; Борда, Коупленд, W Кендалла
src/compare.py       сравнение методов и выбор итогового разбиения
src/dynamics.py      квартальные переходы между типами
src/fca.py           описания типов через формальные понятия
src/network_choice.py обоснование выбора сети (I Морана, нуль-модели)
src/reference.py     справочник МО и полигоны
src/pipeline.py      итоговый прогон после сравнения
src/validate.py      внешняя проверка (η², V Крамера, ARI/AMI)
src/synthetic.py     когда сеть добавляет информацию к признакам (известный ответ)
src/figures.py       рисунки для отчёта
src/landing_data.py  данные для интерактивной страницы
landing/             шаблон и сборка страницы; docs/index.html — готовая страница (GitHub Pages)
reports/report.md    методологический отчёт
tests/               проверки на синтетике с известным ответом
```
