# Потребление против рынка труда: типы локальных экономик муниципалитетов

Конкурс СберИндекса, направление «Кластеризация». **Когда потребление жителей расходится с
трудовой статистикой территории и насколько надёжно мы это видим.** Типология муниципальных
образований (МО) по безналичному потреблению на атрибутированной сети (признаки узлов — 24 месяца
расходов; основная сеть статична, дополнительно — скользящие 12-месячные окна с пересчитанными
связями) и её сопоставление с типологией по рынку труда (муниципальная статистика Росстата).

Страница — один самодостаточный файл: данные и библиотеки D3 и TopoJSON встроены, поэтому она
работает без интернета (шрифты подгружаются при наличии сети). Тексты лицензий библиотек — в
`landing/vendor/` (D3 — ISC, TopoJSON — BSD-3-Clause). На GitHub Pages страница сама показывает
ссылку на репозиторий; для других адресов ссылку можно задать в `config/config.yaml`
(`publication.repo_url`) и пересобрать страницу командой `python landing/build.py`.

## Главное

- 2 016 МО с полным рядом безналичных расходов (2023–2024), четыре семейства рёбер (сходство всех
  признаков узла, синхронная динамика, DTW, дороги) и их мультиплекс; гипотеза о направленных связях
  («столица опережает периферию») проверена — свидетельств систематического опережения не обнаружено.
- 280 вариантов разбиения: k-means, GMM, Уорд, паттерны (Мячин), Leiden, спектральная,
  KEFRiN (реализован по статье Shalileh & Mirkin, 2022) с разными расстояниями и весом сети.
- Выбор — шесть ICVI, агрегирование рангов по Борда и Коупленду (одинаковый победитель),
  устойчивость на подвыборках. Итог по заданному правилу: KEFRiN на мультиплексе, 8 типов. Выбор
  устойчив к удалению дублирующих индексов и занимает 4-е место из 251 на внешней сети (железные
  дороги), но во многом держится на индексе AVU — это показано открыто.
- Финалист с 6 типами устойчивее (ARI на подвыборках 0,81 против 0,67): шесть типов — более
  устойчивое альтернативное разрешение, восемь — основной результат по заданному правилу; самый
  неустойчивый тип («удалённые районы с сезонными пиками», Жаккар 0,48) помечен, у каждого МО на
  странице показана надёжность типа.
- На независимых данных Росстата с типами связано 64% межмуниципальной дисперсии логарифма
  зарплаты (η²); столько же у k-means по тем же признакам (65%), у разбиения только по дорогам —
  40%. Крупные контрасты во многом воспроизводятся по одним признакам; сеть меняет границы и
  повышает пространственную концентрацию типов (41,7% МО в крупнейшей связной части своего типа
  против 33,5% у k-means с K = 8) — это сказано прямо.
- Ретроспективное квартальное присвоение: 68% МО сохраняют тип все 8 кварталов (58% без сетевого
  члена, 72% при двойном весе сети).
- Типология рынка труда (Росстат, 6 типов) связана с типологией потребления, но не совпадает
  (V Крамера 0,46). Отношение безналичных расходов к фонду оплаты труда на жителя — от 3,14 в
  сельских районах с низкими расходами до 1,0 на Крайнем Севере. Три из четырёх разобранных
  расхождений согласуются с разницей учёта: занятость — по месту работы, расходы — по месту
  жительства (вахта, Иннополис, пригород). Скопления расхождений (локальный I Морана, 49 995
  перестановок, поправка на множественные сравнения): «тратят больше» — Тверская и Московская
  области, Карелия; «тратят меньше» — Татарстан и Чувашия.
- Данные Росстата подготовлены по явным правилам с проверками баланса и согласованности (отраслевые
  доли внутри года, иерархия торговых объектов, среднегодовая численность, структурные нули);
  ошибки первой версии подготовки исправлены, основные содержательные выводы сохранились (отчёт, 8.1 и 8.7).
- Полный прогон с пустого каталога результатов воспроизводит все файлы результатов, рисунки и
  страницу побайтно (`reports/cold_start_check.md`).

## Как воспроизвести

```bash
pip install -r requirements.txt
# данные
python src/download.py                      # архив конкурса с официального адреса
python src/download.py --dict t_dict_municipal.rar   # справочник МО СберИндекса (скачать вручную)
python src/extract_bdmo.py ПАПКА_С_АРХИВАМИ # муниципальная статистика: нужные показатели из архивов Точно
# всё остальное одной командой
python run_all.py                           # ~70 мин на 2 ядрах; --skip-compare — без сравнения 280 вариантов
```

По шагам:

```bash
python src/download.py --check              # проверка файлов и контрольных сумм (другая версия данных — ошибка;
                                            #   --allow-new-data, если так и задумано)
python src/compare.py                       # сетка методов → 6 ICVI → ранжирование → устойчивость (~30 мин на 2 ядрах)
python src/descriptives.py                  # выборка, покрытие, закон Энгеля, тест опережения столиц
python src/robustness.py                    # устойчивость выбора к набору индексов и внешней сети, вклад сети
python src/pipeline.py                      # итоговое разбиение, описания АФП, динамика, проверки
python src/type_stability.py                # устойчивость типов и финалисты K = 6, 7, 8 (~25 мин)
python src/optimum_check.py                 # перезапуски KEFRiN, связь финалистов с итогом, фактический ξ
python src/windows.py                       # скользящие 12-месячные окна: связи и типы во времени
python src/labor_run.py                     # типология рынка труда, согласие, карта расхождений
python src/sensitivity.py                   # слои сети, равные массы, ILR (η² — по таблице Росстата из labor_run)
python src/cases.py                         # разобранные случаи
python src/synthetic.py                     # синтетическая проверка KEFRiN
python src/figures.py                       # рисунки отчёта
python src/landing_data.py && python landing/build.py   # интерактивная страница → docs/index.html
python src/manifest.py                      # манифест SHA-256 результатов
python -m pytest tests -q                   # проверки методов и подготовки данных (28 тестов)
```

Все параметры — в `config/config.yaml`; другой конфиг: `SBER_CONFIG=path/to/config.yaml`.
Случайность фиксирована (`seed`).

## Данные

| Источник | Что берём | Лицензия |
|---|---|---|
| Архив конкурса СберИндекса (`hackathonlicence.zip`) | безналичные расходы по МО и категориям за 2023–2024 гг. (месяц), индекс доступности рынков, расстояния между центрами МО | CC BY-SA 4.0 |
| [Справочник МО СберИндекса](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities) | названия, регионы, ОКТМО по версиям, полигоны | условия СберИндекса |
| [Муниципальная статистика России (Точно)](https://tochno.st/datasets/bdmo) | зарплата и численность работников, население, розничная торговля | CC BY 4.0 |

Данные в репозиторий не кладутся. Архив конкурса скачивает `src/download.py`; справочник МО и три
архива муниципальной статистики (разделы 2, 31, 32 «по показателям», ~330 ГБ без сжатия) скачиваются
вручную, `src/extract_bdmo.py` берёт из них нужное (~15 МБ).

## Окружение и проверка результатов

- **Окружение.** `requirements.txt` — минимальные версии; `requirements-lock.txt` — точное окружение,
  на котором получены опубликованные результаты (Python 3.11).
- **Журнал прогона.** `run_all.py` пишет машинный журнал `reports/run_log.json`: шаги, время, коды
  возврата, версия Python. Последний шаг строит манифест контрольных сумм
  `reports/manifest_sha256.txt`; сверить свои результаты с опубликованными —
  `python src/manifest.py --check`.
- **Проверка с нуля.** Полный прогон с пустого каталога результатов воспроизвёл все файлы
  результатов, рисунки и страницу побайтно (`reports/cold_start_check.md`). Хеши коммитов, на которые
  ссылаются документы проверки, сохранены: история git не переписывалась.
