# Потребление против рынка труда: типы локальных экономик муниципалитетов

Конкурс СберИндекса, направление «Кластеризация». Типология муниципальных образований (МО)
по безналичному потреблению на динамической атрибутированной сети и её сопоставление с
типологией по рынку труда (муниципальная статистика Росстата).

Отчёт: [`reports/report.md`](reports/report.md). Интерактивная страница: `docs/index.html` —
один самодостаточный файл, работает без интернета (библиотеки d3 и topojson встроены;
лицензии ISC и BSD-3, копии в `landing/vendor/`). Для публикации включите GitHub Pages для папки `docs`.

## Главное

- 2 016 МО с полным рядом безналичных расходов (2023–2024), четыре семейства рёбер (сходство всех
  признаков узла, синхронная динамика, DTW, дороги) и их мультиплекс; гипотеза о направленных связях
  («столица опережает периферию») проверена — свидетельств систематического опережения не обнаружено.
- 280 вариантов разбиения: k-means, GMM, Уорд, паттерны (Мячин), Leiden, спектральная,
  KEFRiN (реализован по статье Shalileh & Mirkin, 2022) с разными расстояниями и весом сети.
- Выбор — шесть ICVI, агрегирование рангов по Борда и Коупленду (одинаковый победитель),
  устойчивость на подвыборках. Итог по заданному правилу: KEFRiN на мультиплексе, 8 типов. Выбор
  устойчив к удалению дублирующих индексов и занимает 4-е место из 251 на внешней сети (железные
  дороги), но во многом держится на индексе AVU — это показано открыто.
- Финалист с 6 типами устойчивее (ARI на подвыборках 0,81 против 0,67): шесть типов — устойчивое
  ядро, восемь — детализация; самый неустойчивый тип («удалённые районы с сезонными пиками»,
  Жаккар 0,48) помечен, у каждого МО на странице показана надёжность типа.
- На независимых данных Росстата типы объясняют 64% различий в логарифме зарплаты между МО
  (разбиение только по дорогам — 40%).
- Ретроспективное квартальное присвоение: 68% МО сохраняют тип все 8 кварталов (58% без сетевого
  члена, 72% при двойном весе сети).
- Типология рынка труда (Росстат, 6 типов) связана с типологией потребления, но не совпадает
  (V Крамера 0,46). Отношение безналичных расходов к фонду оплаты труда на жителя — от 3,15 в
  сельских районах с низкими расходами до 1,0 на Крайнем Севере. Крупнейшие расхождения создаёт учёт
  занятости по месту работы, а расходов — по месту жительства (вахта, Иннополис, пригороды). Значимые скопления расхождений (с поправкой на
  множественные сравнения): «тратят больше» — Тверская область, Карелия, Псковская область;
  «тратят меньше» — Татарстан и Чувашия.

## Как воспроизвести

```bash
pip install -r requirements.txt
# данные
python src/download.py                      # архив конкурса с официального адреса
python src/download.py --dict t_dict_municipal.rar   # справочник МО СберИндекса (скачать вручную)
python src/extract_bdmo.py ПАПКА_С_АРХИВАМИ # муниципальная статистика: нужные показатели из архивов Точно
# всё остальное одной командой
python run_all.py                           # ~1,5 ч на 2 ядрах; --skip-compare — без сравнения 280 вариантов
```

По шагам:

```bash
python src/download.py --check              # проверка файлов и контрольных сумм (другая версия данных — ошибка;
                                            #   --allow-new-data, если так и задумано)
python src/compare.py                       # сетка методов → 6 ICVI → ранжирование → устойчивость (~30 мин на 2 ядрах)
python src/descriptives.py                  # выборка, покрытие, закон Энгеля, тест опережения столиц
python src/robustness.py                    # устойчивость выбора к набору индексов и внешней сети
python src/pipeline.py                      # итоговое разбиение, описания АФП, динамика, проверки
python src/type_stability.py                # устойчивость типов и финалисты K = 6, 7, 8 (~25 мин)
python src/optimum_check.py                 # перезапуски KEFRiN, связь финалистов с итогом
python src/sensitivity.py                   # слои сети, равные массы, ILR
python src/labor_run.py                     # типология рынка труда, согласие, карта расхождений
python src/cases.py                         # разобранные случаи
python src/synthetic.py                     # синтетическая проверка KEFRiN
python src/figures.py                       # рисунки отчёта
python src/landing_data.py && python landing/build.py   # интерактивная страница → docs/index.html
python -m pytest tests -q                   # проверки методов на синтетике
```

Все параметры — в `config/config.yaml`; другой конфиг: `SBER_CONFIG=path/to/config.yaml`.
Случайность фиксирована (`seed`).

## Данные

| Источник | Что берём | Лицензия |
|---|---|---|
| Архив конкурса СберИндекса (`hackathonlicence.zip`) | безналичные расходы по МО и категориям за 2023–2024 гг. (месяц), индекс доступности рынков, расстояния между центрами МО | CC BY-SA 4.0 |
| [Справочник МО СберИндекса](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities) | названия, регионы, ОКТМО по версиям, полигоны | условия СберИндекса |
| [Муниципальная статистика России (Точно)](https://tochno.st/datasets/bdmo) | зарплата и численность работников, население, розничная торговля | CC BY 4.0 |

Данные в репозиторий не кладутся. Архив конкурса скачивает `src/download.py`; справочник МО и три
архива муниципальной статистики (разделы 2, 31, 32 «по показателям», ~330 ГБ без сжатия) скачиваются
вручную, `src/extract_bdmo.py` берёт из них нужное (~15 МБ).

## Структура

```
config/config.yaml   все параметры
src/data.py          загрузка и проверка данных, базовая выборка (2 016 МО с полным рядом)
src/features.py      признаки МО: структура (CLR долей), уровень, динамика; квартальные признаки
src/graphs.py        четыре семейства рёбер: все признаки узла, синхронная динамика, DTW, дороги
src/methods.py       k-means, GMM, Уорд, паттерны (Мячин), Leiden, спектральная, KEFRiN
src/icvi.py          SW, CH, S_Dbw, AVI, AVU, MQ; Борда, Коупленд, W Кендалла
src/compare.py       сравнение методов и выбор итогового разбиения
src/dynamics.py      квартальные переходы между типами
src/fca.py           описания типов через формальные понятия
src/network_choice.py обоснование выбора сети (I Морана, нуль-модели)
src/reference.py     справочник МО и полигоны
src/pipeline.py      итоговый прогон после сравнения
src/extract_bdmo.py  выборка показателей из архивов муниципальной статистики (~330 ГБ → 15 МБ)
src/labor.py         рынок труда: привязка ОКТМО, признаки, локальный I Морана, регрессии
src/labor_run.py     типология рынка труда, сопоставление с потреблением, расхождения
src/descriptives.py  выборка, покрытие, закон Энгеля, паттерны, тест «столица опережает периферию»
src/robustness.py    устойчивость выбора к набору индексов и к внешней сети оценки
src/type_stability.py устойчивость каждого типа (Жаккар), финалисты K = 6, 7, 8, надёжность типа МО
src/optimum_check.py критерий KEFRiN у итога и перезапусков, сопряжённость финалистов с итогом
src/sensitivity.py   исключение слоёв мультиплекса, равные массы слоёв, ILR вместо CLR
src/cases.py         разобранные случаи расхождений (отбор по правилу)
run_all.py           полный прогон одной командой
src/validate.py      внешняя проверка (η², V Крамера, ARI/AMI)
src/synthetic.py     когда сеть добавляет информацию к признакам (известный ответ)
src/figures.py       рисунки для отчёта
src/landing_data.py  данные для интерактивной страницы
landing/             шаблон и сборка страницы; docs/index.html — готовая страница (GitHub Pages)
reports/report.md    методологический отчёт
tests/               проверки на синтетике с известным ответом
```

## Проверено на

Python 3.11; numpy 2.x, pandas 2.x/3.x, scikit-learn 1.8, scipy 1.17, python-igraph 1.0, leidenalg 0.12,
dtaidistance 2.5, statsmodels 0.15, geopandas 1.x. Повторный прогон даёт идентичные результаты.

## Использование ИИ

Код и тексты подготовлены с помощью ИИ-ассистента (Claude, Anthropic). Постановка задачи,
выбор методов, проверка результатов и выводы — автора.
