# Типы локальных экономик муниципалитетов: безналичное потребление и рынок труда

Конкурс СберИндекса, направление «Кластеризация». **Когда потребление жителей расходится с
трудовой статистикой территории и насколько надёжно мы это видим.** Типология муниципальных
образований (МО) по безналичному потреблению на атрибутированной сети (признаки узлов — 24 месяца
расходов; основная сеть статична, дополнительно — скользящие 12-месячные окна с пересчитанными
связями) и её сопоставление с типологией по рынку труда (муниципальная статистика Росстата).

## Коротко, без формул

Мы разделили 2 016 муниципалитетов на восемь типов по тому, сколько и на что их жители тратят по
картам, учитывая, какие муниципалитеты связаны дорогами и чьи расходы меняются похоже. Отдельно, без
данных о расходах, построили шесть типов рынка труда по статистике Росстата и сравнили два взгляда.

1. **Типы содержательны и переносятся.** Они связаны с зарплатами Росстата, которые в построении не
   участвовали, — и так же сильно на регионах, которые при построении типов отложили.
2. **Потребление и рынок труда совпадают лишь частично.** Там, где расходы жителей сильно отличаются
   от учтённого фонда оплаты труда, чаще дело в учёте (работают в одном месте, живут в другом; вахта),
   а не в необычных расходах.
3. **Территории для сравнения** по профилю расходов подбираются не хуже, чем по зарплате и
   численности, а по всей стране — лучше; иногда такой подбор показывает расхождение, которое
   сравнение зарплат пропускает (Верхнеуслонский район с Иннополисом).
4. **Что не доказано.** Сеть почти не усиливает связь типов с рынком труда по сравнению с обычным
   k-means и не делает типы устойчивее во времени; объяснения расхождений — гипотезы.

| Термин | Что значит |
|---|---|
| МО | муниципальное образование верхнего уровня: район, округ, город |
| KEFRiN | вариант k-means, который группирует МО сразу по признакам и по связям сети |
| мультиплекс | сеть из трёх слоёв близости: дороги, синхронная динамика расходов, похожая форма траектории |
| ICVI | индексы качества разбиения без «правильного ответа»: насколько типы компактны и связны |
| ARI | совпадение двух разбиений (1 — одинаковые, 0 — как случайные); на подвыборках — устойчивость |
| Жаккар | устойчивость отдельного типа на подвыборках |
| η² | доля различий показателя между МО, связанная с типами |
| R² вне выборки | то же на МО регионов, не участвовавших в построении типов |
| «расходы ÷ фонд оплаты» | безналичные расходы на жителя к фонду оплаты труда на жителя — индикатор расхождения двух взглядов, а не норма потребления |

## Главное

- 2 016 МО с полным рядом безналичных расходов (2023–2024), четыре семейства рёбер (сходство всех
  признаков узла, синхронная динамика, DTW, дороги) и их мультиплекс; гипотеза о направленных связях
  («столица опережает периферию») проверена — свидетельств систематического опережения не обнаружено.
- 280 вариантов разбиения: k-means, GMM, Уорд, паттерны (Мячин), Leiden, спектральная,
  KEFRiN (реализован по статье Shalileh & Mirkin, 2022) с разными расстояниями и весом сети.
- Выбор — шесть ICVI, агрегирование рангов по Борда и Коупленду (одинаковый победитель),
  устойчивость на подвыборках. Итог по заданному правилу: KEFRiN на мультиплексе, 8 типов. Выбор
  устойчив к удалению дублирующих индексов и занимает 4-е место из 251 на внешней сети (железные
  дороги), но во многом держится на индексе AVU — это показано открыто.
- Финалист с 6 типами устойчивее (ARI на подвыборках 0,81 против 0,67), поэтому восемь типов —
  компромисс по совокупности критериев с допустимой устойчивостью, а не самый устойчивый вариант.
  Седьмой тип отделяет «северные ресурсные территории» и даёт почти весь прирост связи с рынком труда
  (η² логарифма зарплаты 0,59 → 0,64); восьмой («удалённые районы с сезонными пиками», Жаккар 0,48)
  почти ничего к ней не добавляет и неустойчив — он и МО с надёжностью типа ниже 0,6 на странице
  помечены как пограничные.
- На независимых данных Росстата с типами связано 64% межмуниципальной дисперсии логарифма
  зарплаты (η²); столько же у k-means по тем же признакам (65%), у разбиения только по дорогам —
  40%. Крупные контрасты во многом воспроизводятся по одним признакам; сеть меняет границы и
  повышает пространственную концентрацию типов (41,7% МО в крупнейшей связной части своего типа
  против 33,5% у k-means с K = 8) — это сказано прямо.
- **Перенос на новые регионы** (`src/extra_checks.py`): типы строятся заново на 4/5 регионов, МО
  отложенных регионов относятся к ближайшему типу. R² вне выборки для логарифма зарплаты — 0,64 (как
  внутри выборки), у k-means — 0,63, у доступности рынков, широты, размера и вида МО — не больше 0,21.
  Выигрыш сети над k-means по зарплате и фонду оплаты устойчив во всех делениях, но мал (0,01–0,02).
- **Подбор территорий для сравнения:** аналоги по профилю расходов (без данных о зарплате) ближе к МО
  по пяти независимым показателям Росстата, чем «двойники» по зарплате и численности, по всей стране
  (0,47 против 0,55 стандартного отклонения) и не хуже внутри региона (0,44 и 0,44).
- Ретроспективное квартальное присвоение: 68% МО сохраняют тип все 8 кварталов (58% без сетевого
  члена, 72% при двойном весе сети).
- Типология рынка труда (Росстат, 6 типов) связана с типологией потребления, но не совпадает
  (V Крамера 0,46). Отношение безналичных расходов к фонду оплаты труда на жителя — от 3,14 в
  сельских районах с низкими расходами до 1,0 на Крайнем Севере. Три из четырёх разобранных
  расхождений согласуются с разницей учёта: занятость — по месту работы, расходы — по месту
  жительства (вахта, Иннополис, пригород). Скопления расхождений (локальный I Морана, 49 995
  перестановок, поправка на множественные сравнения): «тратят больше» — Тверская и Московская
  области, Карелия; «тратят меньше» — Татарстан и Чувашия.
- Данные Росстата подготовлены по явным правилам с проверками баланса и согласованности (отраслевые
  доли внутри года, иерархия торговых объектов, среднегодовая численность, структурные нули);
  ошибки первой версии подготовки исправлены, основные содержательные выводы сохранились (приложение, 8.1 и 8.7).
- Полный прогон с пустого каталога результатов воспроизводит результаты, рисунки и страницу
  побайтно; манифест — 82 контрольные суммы (72 актуальных результата и 10 исторических файлов
  `labor_v1/`), 0 расхождений (`reports/cold_start_check.md`).

- Методологические решения и интерпретации привязаны к литературе: экономика потребления и доходов,
  пространственные рынки труда, композиционные данные, кластеризация атрибутированных и многослойных
  сетей, валидация и устойчивость, пространственная статистика (раздел «Связь с литературой» приложения:
  что взято, что сделано иначе, где граница применимости каждой ссылки).

## Как воспроизвести

```bash
pip install -r requirements.txt
# данные: выгрузка муниципальной статистики уже в репозитории (data/external/bdmo/)
python src/download.py                      # архив конкурса с официального адреса
python src/download.py --dict t_dict_municipal.rar   # справочник МО СберИндекса (скачать вручную)
python src/download.py --check              # контрольные суммы
# всё остальное одной командой
python run_all.py                           # ~2 ч на 2 ядрах; --skip-compare — без сравнения 280 вариантов
# PDF отчёта (отдельно: нужны Chromium и шрифт HSE Sans, см. requirements-docs.txt и ниже)
python reports/build_pdf.py                 # reports/report.md → reports/report.pdf и копия в docs/
```

По шагам:

```bash
python src/download.py --check              # проверка файлов и контрольных сумм (другая версия данных — ошибка;
                                            #   --allow-new-data, если так и задумано)
python src/compare.py                       # сетка методов → 6 ICVI → ранжирование → устойчивость (~30 мин на 2 ядрах)
python src/descriptives.py                  # выборка, покрытие, закон Энгеля, тест опережения столиц
python src/robustness.py                    # устойчивость выбора к набору индексов и внешней сети, вклад сети
python src/pipeline.py                      # итоговое разбиение, описания АФП, динамика, проверки
python src/type_stability.py                # устойчивость типов и финалисты K = 6, 7, 8 (~25 мин)
python src/optimum_check.py                 # перезапуски KEFRiN, связь финалистов с итогом, фактический ξ
python src/windows.py                       # скользящие 12-месячные окна: связи и типы во времени
python src/windows_sensitivity.py           # окна без полугодовых контрастов и с другими seed (~20 мин)
python src/labor_run.py                     # типология рынка труда, согласие, карта расхождений
python src/sensitivity.py                   # слои сети, равные массы, ILR (η² — по таблице Росстата из labor_run)
python src/cases.py                         # разобранные случаи
python src/extra_checks.py                  # перенос на новые регионы, 6/7/8 типов, подбор аналогов (~5 мин)
python src/synthetic.py                     # синтетическая проверка KEFRiN
python src/figures.py                       # рисунки отчёта
python src/landing_data.py && python landing/build.py   # интерактивная страница → docs/index.html
python src/manifest.py                      # манифест SHA-256 результатов
python -m pytest tests -q                   # проверки методов и подготовки данных (31 тест)
```

Все параметры — в `config/config.yaml`; другой конфиг: `SBER_CONFIG=path/to/config.yaml`.
Случайность фиксирована (`seed`).

## Окружение и проверка результатов

- **Окружение.** `requirements.txt` — минимальные версии; `requirements-lock.txt` — точные версии
  основных пакетов, на которых получены опубликованные результаты (Python 3.11.15);
  `requirements-freeze.txt` — полный снимок окружения (`pip freeze`, включая транзитивные
  зависимости и сборку BLAS/LAPACK numpy).
- **Журнал прогона.** `run_all.py` пишет машинный журнал `reports/run_log.json`: шаги, время, коды
  возврата, версия Python. Последний шаг строит манифест контрольных сумм
  `reports/manifest_sha256.txt`; сверить свои результаты с опубликованными —
  `python src/manifest.py --check`.
- **Проверка с нуля.** Полный прогон итогового коммита с пустого каталога результатов воспроизвёл
  все файлы результатов, рисунки и страницу побайтно (`reports/cold_start_check.md`). Хеши коммитов,
  на которые ссылаются документы проверки, указаны по текущей истории; соответствие прежним
  хешам — в начале `reports/cold_start_check.md`.
- **Оформление PDF.** Шрифт отчёта — HSE Sans (НИУ ВШЭ, дизайнер Юрий Гордон;
  https://it.hse.ru/en/hsesans/). Он встроен в PDF только для просмотра и печати и в репозиторий не
  входит; для пересборки PDF его нужно установить в систему (без него сборка подставит PT Sans).
  Страница использует PT Sans и PT Serif (ParaType, SIL Open Font License) через Google Fonts.
