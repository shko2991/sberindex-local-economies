## 3. Сезонный риск оконного анализа — проверено, вывод сужен

Ваш контрпример приведён в §7.1. Новый скрипт `src/windows_sensitivity.py` (включён в `run_all.py`)
считает два варианта:
- основной, с seed 42, 43, 44;
- без `growth_rel` и `mp_shift`: блок динамики из трёх признаков перевзвешен делением на √3, seed те
  же.

Самопроверка: метки основного варианта с seed 42 полностью совпадают с `window_labels.parquet`.

| Вариант | Неизменная метка: KEFRiN / k-means | ARI окон 2023 и 2024: KEFRiN / k-means | Кандидатов (из них среди 33) |
|---|---|---|---|
| 12 признаков, seed 42 / 43 / 44 | 45,0 / 44,5 / 46,2% против 32,5 / 33,4 / 32,2% | 0,52 / 0,51 / 0,52 против 0,45 / 0,53 / 0,44 | 33 (33) / 66 (22) / 24 (20) |
| без полугодовых, seed 42 / 43 / 44 | 37,0 / 42,9 / 41,2% против 50,2 / 49,0 / 50,8% | 0,40 / 0,38 / 0,36 против 0,49 / 0,50 / 0,50 | 72 (7) / 61 (10) / 46 (8) |

**Что сохранилось:**
- доля МО с неизменной меткой и её распределение по типам при смене seed;
- ядро (Москва — 95–99%, растущие города — 64–78%) во всех шести запусках.

**Что не сохранилось и как изменён текст:**
- **Преимущество сети по устойчивости во времени.** Без полугодовых контрастов k-means устойчивее
  KEFRiN, а при seed 43 ARI между годами у k-means выше. Утверждение о преимуществе сети снято. Результат
  чувствителен к полугодовым контрастам; это согласуется с риском влияния местной сезонности, но
  проверка не отделяет сезонность от реальных изменений потребления (уточнено после проверки
  `b2146c9`).
- **Список 33 кандидатов.** При всех трёх seed повторяются 14 из 33, во всех шести запусках — 2
  (Борзинский район, Магадан). Список назван «кандидатами на переход по объявленному правилу». Правило описано точно по коду: k-means
  должен показать тот же переход A → B, то есть совпасть с KEFRiN на обоих концах, а не только в конце
  (правило «совпала конечная метка» дало бы 54 кандидата).
  Совпадение с k-means описано как контроль другого алгоритма на тех же данных, а не независимая
  проверка; экономические события независимо не установлены.
- **Петербург и Крайний Север.** Без полугодовых признаков при части seed они не сохраняют
  постоянную метку. В выводе они отнесены к ядру только для варианта с 12 признаками.

Итоговая доля МО с неизменной меткой в окнах дана диапазоном 37–46%. Добавлены оговорки о
перекрытии окон на 9 месяцев и о том, что доля совпадений зависит от согласования меток с итогом,
а ARI — нет.
